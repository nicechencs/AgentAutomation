# AgentAutomation

本地自托管的 Agent 任务自动化系统，计划使用 n8n、Python/FastAPI 和 SQLite，接入 Claude Code CLI 与 OpenAI Codex CLI。支持可配置流程节点、Agent/模型选择及审批判断；任务不限于编程。代码任务使用 Git Worktree/分支隔离，优先并行执行，经过验证与审查后提交、合并，并支持工作区和分支清理。

当前处于需求分析阶段，尚未实现服务或部署流程。

支持注册多个目标仓库，第一版运行一个项目；该项目内有条件时优先并行，无法并行时可串行编排。未来考虑 Windows、macOS、Linux，首发支持范围仍待确定。

已确认采用并行执行与串行集成、合并候选重新验证、任务/集成/清理结果分开记录、统一节点契约、项目→任务→节点配置继承、非编程产物验收，以及平台执行适配和分平台验证。

具体目标分支、合并方法、自动放行条件、默认审批点、模型组合、并发数、清理保留期及首发环境仍待确定。文档中未采纳的实现建议不代表已确认方案；默认禁止自动 Push 和部署。
