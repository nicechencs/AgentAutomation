# AgentAutomation UI 交互原型

保留原有浏览器演示工作台，并提供独立的“n8n 运行”页面连接本地 FastAPI Runner。n8n 页面调用真实后端并触发实际 n8n 编排，任务使用 Fake Agent；不执行真实 CLI 或 Git。

## 启动

需要 Node.js 20+，没有运行时 npm 依赖，不需要安装包。

```sh
npm --prefix ui run dev
```

打开 http://127.0.0.1:4173 。默认仅监听本机；端口可用 `PORT` 环境变量覆盖。也可以在 `ui/` 下运行 `npm run dev`。

## 可体验的交互

- 任务工作台：筛选/搜索任务、查看阶段、验收标准、Review findings、模拟日志；新建开发或本地产物任务。
- 运行控制：暂停/恢复、并发上限、依赖等待、有界修复、审查通过与集成入口。
- 节点配置：Coding 和 Review 可选择不同 Agent 与模拟模型。
- 流程编排：两条模板、选择/修改节点、追加审批/判断/等待节点。这里只验证配置入口，实际编排仍由 n8n 承担。
- 集成与清理：集成检查与审批确认、冲突等待人工、已集成工作区清理确认及保护条件。
- 项目仓库：查看/切换虚构项目、添加演示仓库记录。
- 设置：并发、Review 轮数、时间上限、审批策略预览，以及人工恢复和取消入口。
- 明暗主题和窄屏布局。

以上演示工作台的记录均为虚构数据。操作仅修改浏览器页面内存，刷新即重置，不能作为真实审批或执行记录。“重置演示”只恢复演示状态，不影响独立 n8n 运行。

## n8n 运行页面

本地 FastAPI Runner 启动后，打开 http://127.0.0.1:8000/#runner ，或从侧栏“n8n 运行”进入。原 Node 预览服务 4173 只提供静态文件；在该地址进入新页面会显示连接失败，并提供 8000 地址链接。

1. 核对 Runner 为 `fake` 模式，n8n 已配置且可连接；缺少这些条件时创建按钮不可用。
2. 填写目标，选择开发或本地文档模板、并发数 1/2 和最大阶段调用数 1–30。运行默认期限为 300 秒。
3. 创建后由 Runner 触发 n8n；选择运行查看状态、阶段、n8n 执行 ID、任务日志和事件。页面每 1.5 秒查询，不从浏览器推进阶段。
4. 仅待审批记录提供批准/拒绝按钮。收到回执显示“审批已记录”，后续阶段与完成结果仍以查询为准。
5. 可暂停、恢复、取消运行；取消有确认提示。终态运行不提供控制，恢复仅针对已暂停状态。

写请求携带 `X-UI-Request: 1`，浏览器提供同源 Origin，由 Runner 验证。调用配置已设置只表示配置存在，不代表 n8n 工作流已发布或端到端验收通过。

页面使用同源 `GET /api/health`、`GET /api/runs`（数组）、`GET /api/runs/{id}`，以及创建、`/control`、`/approvals/{approval_id}` 的 POST 接口。创建参数包含 `template`、`goal`、`max_concurrency`、`max_cycles`、`deadline_seconds: 300`。后两类 POST 返回运行对象，页面随后重新查询确认。网络失败不自动重发写请求；先查看后端状态，避免重复创建。查询失败会标注旧数据可能过期，且禁用操作。

真实 n8n 编排与 Fake Agent 结果不等于真实 CLI、Git 或平台权限已验收。任务日志、状态和审批均来自 Runner，演示 fixtures 不参与新页面。后续接入真实 CLI 时需要提供明确的能力信息、候选/目标版本绑定、请求去重标识及实际执行证据；当前接口不代表这些能力已具备。

## 推荐走查路径

1. 初始页面选择 TASK-104，查看审查与日志，然后点击“审批集成”，确认模拟合并。
2. 选择 TASK-103，“要求修复”后批准创建 Fix 会话；模拟进入 Review 后通过。
3. 在“集成与清理”处理待合并任务，观察冲突项保留现场；为 TASK-101 执行模拟安全清理。
4. 在“流程编排”切换本地产物模板，修改 Agent/模型，添加审批节点。
5. 注册新的演示仓库并切换，检查空任务状态，再添加任务。

## 检查

```sh
npm --prefix ui run check
node --check ui/src/runner.js
```

浏览器验证脚本使用 Node.js 24 的内置 WebSocket 与已安装 Chrome，不下载测试包：

```sh
node ui/tests/browser-smoke.mjs
```

运行前先启动本地服务。脚本使用独立临时 Chrome profile，不接管用户浏览器；截图写入 `ui/tests/preview-*.png`，不纳入 Git。Chrome 的具体发现方式以脚本为准。
